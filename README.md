# نومان 🦉

لوحة متابعة مهام عربية بسيطة، فيها بومة لطيفة تصحى وتسلّم عليك وتشجعك.
صفحة واحدة بدون مكتبات ولا إطار عمل: `index.html` و`style.css` و`app.js`.

## الميزات

- **البومة نومان**: مرسومة بالكود (SVG) بأربع حالات: نايمة، صاحية، سعيدة، قلقانة.
  اضغط عليها تصحى وتتمطّط، وتسلّم عليك حسب الوقت وتلخّص مهام اليوم.
- **المهام**: إضافة سريعة مع فئة وأولوية وموعد، وثلاث تبويبات (اليوم، القادمة، المنجزة)،
  وترتيب تلقائي: المتأخرة ثم العاجلة ثم الأقرب موعدًا.
- **الاحتفال والنقاط**: 15 نقطة للعاجلة و10 لغيرها، تُحسب مرة واحدة لكل مهمة،
  وسلسلة أيام متتالية فيها إنجاز.
- **وش أبدأ فيه؟**: يقترح المهمة الأهم ويبرزها.
- **تركيز 25 دقيقة**: عدّاد مع إيقاف مؤقت وإنهاء، و20 نقطة عند الانتهاء.
- **بياناتك عندك**: محفوظة في المتصفح (localStorage)، مع تصدير واستيراد ملف JSON.
- مظهر داكن وفاتح، ويحترم إعداد «تقليل الحركة» في الجهاز.

ما فيه أي اتصال بخدمات خارجية، إلا تحميل خط Tajawal من Google Fonts
(ولو ما تحمّل تُستخدم خطوط النظام).

## التشغيل على جهازك

```bash
git clone https://github.com/saraalamer65-ui/numan-owl.git
cd numan-owl
python3 -m http.server 8000
```

افتح http://localhost:8000 في المتصفح.

### من الجوال (على نفس شبكة الواي فاي)

1. شغّل الأمر بهذا الشكل عشان يقبل اتصالات من الشبكة:
   `python3 -m http.server 8000 --bind 0.0.0.0`
2. اعرف عنوان IP جهازك:
   - ماك: `ipconfig getifaddr en0`
   - ويندوز: `ipconfig` وابحث عن IPv4 Address
   - لينكس: `hostname -I`
3. افتح في جوالك: `http://<عنوان-IP>:8000` مثل `http://192.168.1.20:8000`
4. لو ما فتح، تأكد إن الجدار الناري في جهازك يسمح للمنفذ 8000.

## النشر على GitHub Pages

1. ادمج الـ Pull Request في فرع `main`.
2. في صفحة المستودع على GitHub: **Settings** ← **Pages**.
3. تحت **Build and deployment** اختر **Source: Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/ (root)** واضغط **Save**.
5. انتظر دقيقة أو دقيقتين، وبيظهر الرابط فوق الصفحة:
   `https://saraalamer65-ui.github.io/numan-owl/`
6. من الجوال افتح الرابط، ومن قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية».

> ملاحظة: GitHub Pages للمستودعات الخاصة يحتاج اشتراك مدفوع. لو المستودع خاص وحسابك مجاني،
> خلّه عام (Settings ← General ← Change visibility).
> بياناتك ما تنرفع لأي مكان. تنحفظ في متصفح كل جهاز لحاله، فانقلها بين الأجهزة بالتصدير والاستيراد.

## قائمة اختبار سريعة

1. افتح الصفحة لأول مرة: تشوف البومة نايمة وتطلع منها ZZZ، و4 مهام تجريبية، وحدة منها متأخرة باللون الأحمر.
2. اضغط على البومة: تتمطّط وتصحى وتسلّم عليك، وبعدها تقلق وتنبهك على المهمة المتأخرة.
3. أضف مهمة بدون عنوان: يطلع لك تنبيه. أضف مهمة «عاجلة» بدون موعد: تطلع ثانية بعد المتأخرة.
4. أضف مهمة موعدها «بكرة»: تنتقل لتبويب «القادمة» وتنبض.
5. اضغط «وش أبدأ فيه؟»: يقترح المهمة المتأخرة ويبرزها.
6. أنجز المهمة العاجلة: احتفال وقصاصات و+15. ألغِ إنجازها من «المنجزة» وأنجزها مرة ثانية: النقاط ما تزيد.
7. أنجز مهمة عادية: +10، وتصير السلسلة 🔥 1.
8. اضغط أيقونة الحذف: تطلب «متأكد؟». اضغط مرة ثانية وتنحذف.
9. اضغط «تركيز 25 دقيقة»: يبدأ العدّاد. انتقل لتطبيق ثاني دقيقة وارجع: الوقت صحيح. جرّب «إيقاف مؤقت» ثم «استئناف» ثم «إنهاء».
10. حدّث الصفحة: كل شي باقي، حتى جلسة التركيز لو كانت شغالة.
11. «تصدير» ينزّل ملف JSON. عدّل الملف وخرّب فئة مهمة، وجرب «استيراد»: يرفضه ويوضح السبب. استورد الملف الصحيح: يطلب تأكيد قبل الاستبدال.
12. اضغط زر القمر/الشمس: يتبدّل المظهر، ويبقى على اختيارك بعد التحديث.
13. شغّل «تقليل الحركة» في إعدادات الجوال: الحركات والقصاصات تتوقف.
14. اضغط «نوّمه»: ترجع البومة تنام.
